## Ejercicios 67-72. Toda raíz de un número complejo
**67)**  2 raices cuadradas de 4(Cos 30° + i Sen 30°)
```
n = 2, r = 4, θ = 30°
√r = √4 = 2
θ_k = (30° + 360°k) / 2 ---> 15° + 180°k

k = 0: θ_0 = 15° + 180°(0) = 15° --->
z0 = 2(cos 15° + i sin 15°) 

k = 1: θ_1 = 15° + 180°(1) = 195° --->
z1 = 2(cos 195° + i sin 195°) 
```
