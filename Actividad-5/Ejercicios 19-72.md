## Ejercicios 37-42 División de números complejos  
**37)** (10 - 7i)/(1 + 3i)  

<img width="200" height="130" alt="image" src="https://github.com/user-attachments/assets/b32c51be-9d7c-4b8b-b2e7-2fa91768a551" />  

```
[(10 - 7i) / (1 + 3i)] * (1 - 3i) / (1 - 3i)]
[(10 - 7i)(1 - 3i)] / [1^2 - (3i)^2]
(10 - 37i + 21i^2) / (1 - 9i^2)
(10 - 21 - 37i) / (1 + 9)
(-11 - 37i) / 10
= 1.1 - 3.7i

El resultado es 1.1 - 3.7i
```

**38)** (4 + 2i)/(-1 - 10i)  

<img width="200" height="130" alt="image" src="https://github.com/user-attachments/assets/3ddeb79c-f165-4b4d-b3c2-7d72c37ad4c8" />  

```
[(4 + 2i) / (-1 - 10i)] * [(-1 + 10i) / (-1 + 10i)]
[(4 + 2i) * (-1 + 10i)] / [(-1)^2 - (10i)^2]
(-4 + 42i + 20i^2) / (1 - 100i^2)
(-4 - 20 + 42i) / (1 + 100)
(-24 + 42i) / 101
= -24/101 + 42i/101

El resultado es -24/101 + 42i/101
```

**39)** (1 + 4i)/(-1 - 6i)
