## Simplifica las Siguientes Expresiones
 
**133.** a² · (3a²)² / 2a⁰
 
- (3a²)² = 9a⁴
- Numerador: a² · 9a⁴ = 9a⁶
- Denominador: 2a⁰ = 2(1) = 2
**El resultado es: 9a⁶ / 2**

**134.** (3r³ · 2r³ / 2r·r²)²

**El resultado es: 9r⁶**

## Simplifica los Siguientes Radicales
 
Se descompone el radicando buscando el mayor factor que sea potencia exacta del índice (cuadrado perfecto para índice 2, cuarta potencia perfecta para índice 4).
 
**139.** √(18x³)
 
- 18x³ = 9x² · 2x (9x² es el mayor cuadrado perfecto que divide a 18x³)
- √(9x² · 2x) = √(9x²) · √(2x) = 3x√(2x)
**El resultado es: 3x√(2x)**

## Simplifica las Siguientes Expresiones (Racionalización)
 
Se multiplica numerador y denominador por el conjugado del denominador para eliminar la raíz.
 
**145.** 2 / (5 + 3√3)
 
- Conjugado: (5 − 3√3)
- Denominador: 5² − (3√3)² = 25 − 27 = −2
- Numerador: 2(5 − 3√3) = 10 − 6√3
- Resultado: (10 − 6√3) / (−2) = −5 + 3√3
**El resultado es: 3√3 − 5**
